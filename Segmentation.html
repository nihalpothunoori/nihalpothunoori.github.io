Backbone Discovery

Skills: Segmentation, CUDA, Computer Vision, Torch, PointClouds

Goal

For my research with DASLAB, lead by Shivani Kamtikar.Extract the soft-arm backbone from real-world camera data — this isn't possible in simulation. The backbone will be used for benchmarks and as a performance metric for our diffusion-based path planning.

We've set up 3 cameras around the workspace to capture the arm from multiple angles.

Pipeline

The pipeline works as follows: capture multi-view images of the soft arm, run SAM3 segmentation to isolate the arm from the background, reconstruct a point cloud representation from the segmented views, and then single out the backbone curve using polynomial regression.

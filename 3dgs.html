3D Gaussian Splatting

Overview

For the RoboHacks hackathon, I implemented offline 3D Gaussian Splatting using stereo cameras. Used camera intrinsics to collect depth and rgb images of a scene at different angles. Then ran a COLMAP on all of the images to stitch them together, and then rendered it all as a collection of splats. All processing done on the cloud on H200's. Continuation

Was implementing 3D interaction with objects in the scene for the hackathon, but ran out of time. I ran SAM3 on all of the depth/rgb images to mask out distinct objects. Currently working on identifying the corresponding 3D Gaussian splats for those masks in each frame, with the hopes of being able to move the 3D representations of different objects through space in the scene, using some UI. Because of the robot's odometry, position encoding for these distinct objects were recorded, so I'll know the exact new position in the scene these objects go to.
